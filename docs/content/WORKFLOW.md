# Content workflow

Aim: a few genuinely useful pages that answer what buyers search for. Not hundreds of
near-identical "flats in <sector>" pages, which search engines treat as thin or duplicate
content.

## Steps (tracked in Admin → Content)

1. **Idea.** Add it with a target search phrase and city. One page per real buyer question;
   check nothing on the site already answers it.
2. **Drafting.** Copy a template from this folder. Write from first-hand knowledge and named
   sources (authority websites, RERA portal, metro / expressway project pages). Note sources in
   the idea's *Notes*.
3. **Needs review.** A second person checks facts, prices (must match current builder price lists,
   with a date), RERA numbers, and that no returns or appreciation are promised.
4. **Approved.** Ready to publish. Publishing is always manual: there is no auto-posting.
5. **Published.** Paste the live link. The weekly report counts it.

## Where to publish

The site has no blog yet. Until it does, publish guides as:

- a Google Business Profile post (short version + link to the relevant `/projects?city=…` page), and
- a LinkedIn article or post,

or ask for a `/guides/[slug]` section to be added to the site (a follow-up development task).

## Rules

- Every fact that can change (price, possession date, distance, approval status) gets an "as of
  <month year>" and a source.
- Only use photos you took or have written permission to use.
- Link to 2–5 relevant live listings, never to listings that are drafts or hidden.
- Don't publish the same text in several places with only the place name changed.
